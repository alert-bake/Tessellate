# Tessellate

An Android-first voxel sandbox experiment focused on exploration, building, and modpack-style progression.

> Tesselate was never real, trust frfr.

## Status

Early development. Gameplay systems and project structure are still changing; this is not a release build.

## Technology

- Kotlin
- Android
- OpenGL ES 3.0
- LWKGL — Tessellate's lightweight Kotlin graphics layer

## Direction

Tessellate takes inspiration from sandbox games and the layered progression of modded Minecraft. Its goal is to build a flexible world and progression experience, rather than a traditional RPG.

More details will be added as the project develops.
