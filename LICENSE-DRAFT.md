## 1. Purpose and interpretation

TSL is intended to be a copyleft software license. It is designed to allow use, study, modification, and redistribution while preserving attribution, requiring source availability for distributed covered works, and preventing recipients from using intellectual-property claims to take control of or obstruct the covered project.

This draft must be interpreted according to its actual wording and applicable law. It does not create rights that the Licensor or a Contributor does not legally hold or have authority to grant.

4.5. Merely using or running an unmodified copy of the Covered Work privately, without conveying it or making it available for remote interaction by users, does not by itself trigger a source-distribution obligation under this section.

4.6. **Network use of modified versions.** If You modify the Covered Work and operate that modified version so that it supports interaction with users remotely through a computer network, You must prominently offer all users interacting with it remotely an opportunity to obtain the complete Corresponding Source of that modified version. The offer must be made through a network server at no charge and by a standard or customary means of facilitating software copying. This obligation applies whether the service is commercial or non-commercial.

4.7. **Corresponding Source for network use.** The Corresponding Source must include the source code for the modified version actually operated, including modifications to the Covered Work, associated interface definition files, and scripts and materials necessary to generate, install, run, and modify that version. It does not include system libraries or unmodified general-purpose tools that are not part of the Covered Work. 4.8. **Form and access.** The source offer must be clear, durable for as long as the network service is offered, and sufficient for users to obtain the Corresponding Source without paying a source-access fee. If the service provides a user interface, the offer should be placed in or linked from a location users can reasonably find, such as its legal notices, about page, or source-code link.

4.9. **No broader publication duty.** This network-use condition applies to the modified Covered Work made available for remote interaction. It does not, by itself, require publication of unrelated software, independent services, private modifications that are not offered for remote interaction, or the operator's entire infrastructure.

4.10. **No evasion by hosting.** A Licensee may not avoid the obligations of this section merely by providing access to a modified Covered Work over a network instead of distributing copies of it.

4.11. The source offer must identify the exact version of the modified Covered Work being operated and provide a practical way to obtain the matching Corresponding Source. A generic link to an unrelated repository, an outdated branch, or source for a different release does not satisfy this requirement.

4.12. If access to the network service requires an account, the source offer must be available to Network Users without requiring a paid subscription or purchase. Corresponding Source need not contain passwords, private keys, access tokens, personal data, or deployment secrets. If such items are necessary to operate a deployment, You may replace them with documented configuration placeholders and instructions that allow a recipient to supply their own values.

4.13. A source offer may be fulfilled by providing a link to a source-code repository or downloadable archive, provided that the material corresponds to the version actually operated and remains available for as long as that version is offered to users.

4.14. **Installation information for user products.** If You distribute Object Code in, with, or specifically for a User Product in a transaction that transfers possession or use of that product to a recipient, and You or a third party retain the ability to install modified Object Code on that product, You must provide the information, methods, and authorization procedures necessary for the recipient to install and run a modified version, to the extent required by applicable law.
